# The plugin menu

These are under **Plugins → Appliance Monitor**.

| Menu item | What it does |
|---|---|
| **Dump Appliance State (event log)** | Writes one line to the Event Log for each appliance, showing its cycle state, the current watts, when the last cycle started and finished, how long it ran, its highest draw and energy, and whether the door-ready and socket reminders have gone out. The times are in the count-of-seconds form the [Your appliances](devices.md) page explains. It is the quickest way to see what the plugin thinks is going on. |
| **Toggle Timestamps in Log (on/off)** | Every line the plugin writes to the log starts with the time to the thousandth of a second, which helps when lining events up with other plugins. This turns that on or off. It is on to start with, and stays as you leave it. |
| **Show Plugin Info** | Writes the plugin's version, details of your Mac and Indigo, how often it reads the meters, how many appliances it is watching and whether timestamps are on, to the log. It is useful to include if you ask for help on the Indigo forum. |
| **About Appliance Monitor** | Opens this project's page on GitHub. |
